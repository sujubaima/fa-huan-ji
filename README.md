# 法环记

《法环记》是一部基于《艾尔登法环》世界观与人物故事创作的传统传奇戏曲改编作品。以曲牌唱词、人物宾白与科介展开交界地的纷争，探索传统文学体裁在当代游戏题材中的表达空间。

目前已完成前十六出剧本初稿，正文约 2.5 万字，项目持续创作中。

## 文本说明

- 各出保留原稿的文字、段落顺序及曲牌标记。
- 曲辞：唱词正文使用**加粗文字**，曲牌名称以【曲牌名】标记。
- 科白：使用普通字重，包括人物宾白，以及括号内的角色、动作和出入场提示；穿插在唱词中的科白同样不加粗。
- 衬字：使用<ins>带下划线的文字</ins>标示，穿插于曲辞中，与加粗的唱词正文区分。
- 字体、字号、行距和分页随阅读环境变化。
- 当前文本为创作初稿，后续将继续修订并补充篇章。
